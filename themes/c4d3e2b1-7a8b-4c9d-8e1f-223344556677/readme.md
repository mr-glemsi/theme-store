# Focus Glance Suite

Freezes, blurs, and dims the background when the Floating URL bar / New Tab is active, preventing background hover interactions.

### Features
- **Configurable Blur:** From light to ultra privacy blur.
- **Dim Levels:** Adjustable darkness, including full blackout mode.
- **Freeze Mode:** Prevents hover events on the background page while the URL bar is open.
- **Optional Visuals:** Subtle macOS-style zoom-out, cinematic vignette, rotating neon RGB border, and CRT scanlines.
- **Click-to-dismiss:** Clicking or right-clicking anywhere outside the URL bar immediately closes it.
